SUNSET HEIST is an original open-world crime game set in Solmar City: steal cars, outrun the Harbor Patrol, and run three story jobs for fixer Mama June as wheelman Rico Vane — all in the browser, with a 3D sunset city, traffic, pedestrians, a wanted level, combat, missions, a minimap HUD and saved progress.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
